# Windows Server and Group Policy Administration

## Project Overview
Administered a Windows Server 2025 environment and practiced Group Policy management in an Active Directory domain using Hyper-V virtual machines.

## Skills Demonstrated
- Managed Windows Server 2025 in a domain environment.
- Worked with Group Policy Objects (GPOs).
- Tested policy application on a domain-joined Windows 11 client.
- Troubleshot Windows services and system configuration.
- Used Windows administrative tools and PowerShell.

## Lab Environment
- Windows Server 2025 Domain Controller
- Windows 11 Domain-Joined Client
- Microsoft Hyper-V
- Active Directory Domain Services
