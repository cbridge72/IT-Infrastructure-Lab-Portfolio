# IT-Infrastructure-Lab-Portfolio

## About This Portfolio

This portfolio showcases hands-on IT infrastructure and technical support experience gained through 26 practical labs using Windows Server 2025, Windows 11, Active Directory, Hyper-V, and PowerShell.

The projects focus on system administration, networking, user account management, security permissions, and real-world troubleshooting scenarios.

## Featured Projects

### 1. [Active Directory Administration](Active-Directory/README.md)
- Active Directory users, groups, and organizational units
- Password resets and account troubleshooting
- Domain authentication and security group management

### 2. [Networking, DNS, and DHCP](Networking-DNS-DHCP/README.md)
- DNS name resolution and connectivity testing
- DHCP and IP address configuration
- Network troubleshooting in a virtualized environment

### 3. [Windows Server and Group Policy](Windows-Server-Group-Policy/README.md)
- Windows Server 2025 administration
- Group Policy configuration and testing
- Windows services and system troubleshooting

### 4. [File Shares and Permissions](File-Shares-Permissions/README.md)
- SMB file sharing and NTFS permissions
- Active Directory security group access
- Troubleshooting access-denied errors

## Lab Environment

- **Server:** Windows Server 2025
- **Client:** Windows 11
- **Virtualization:** Microsoft Hyper-V
- **Directory Services:** Active Directory Domain Services
- **Administration:** PowerShell and Windows administrative tools

## Practical Troubleshooting Experience

Completed hands-on exercises involving user account issues, network connectivity, shared-folder permissions, Windows services, and domain controller health.

One troubleshooting exercise involved verifying why a domain user was denied access to a departmental file share and confirming that a properly authorized user could access the resource.
