
# Active Directory Administration

## Project Overview
Built and administered an Active Directory lab using Windows Server 2025 and a domain-joined Windows 11 client in Hyper-V.

## Skills Demonstrated
- Created and managed Active Directory users, groups, and organizational units (OUs).
- Performed password resets and account troubleshooting.
- Verified security group membership and access permissions.
- Tested domain authentication from a Windows 11 client.
- Used PowerShell for Active Directory administration.

## Lab Environment
- Windows Server 2025 Domain Controller
- Windows 11 Domain-Joined Client
- Microsoft Hyper-V

## Documentation

### Active Directory Users and Organizational Units

Created and organized Active Directory objects within the `corp.berglab.test` domain.

The environment includes custom organizational units for users, groups, servers, and workstations. Test user accounts were created to practice account administration, authentication, group membership, and permissions.
