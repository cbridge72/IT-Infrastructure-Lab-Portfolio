# File Shares and Permissions

## Project Overview
Configured and troubleshot Windows file sharing in a Windows Server 2025 Active Directory lab. Tested access permissions using domain user accounts and security groups.

## Skills Demonstrated
- Configured Windows shared folders.
- Worked with SMB share permissions and NTFS permissions.
- Managed access using Active Directory security groups.
- Tested shared folder access from a domain-joined Windows 11 client.
- Troubleshot access-denied errors.
- Verified that authorized users could access resources while unauthorized users were denied.

## Troubleshooting Example
Investigated a user access issue involving a departmental shared folder.

- Checked the user's Active Directory security group membership.
- Reviewed the permissions required to access the share.
- Verified that a user without the appropriate group membership was denied access.
- Confirmed that an authorized user could create, read, and delete a test file.

## Lab Environment
- Windows Server 2025
- Windows 11 Domain-Joined Client
- Active Directory Domain Services
- Microsoft Hyper-V
